# Your own lists

Sort what you save into lists of your own: "Recipes", "Travel", "Clients",
anything. Profiles and posts have lists of their own: profile lists in
Profiles, media lists in Media. One item can be in many lists.

## Where it works

```
Your own lists
│
├── On Instagram: the card that opens after saving
├── KeepKeep's toolbar icon
│   ├── Profiles
│   └── Media
└── The KeepKeep app
    ├── Media
    ├── Profiles
    └── the side panel of a profile or a post
```

## What you can do

| | Card on Instagram | Toolbar icon | KeepKeep app |
| --- | --- | --- | --- |
| Add to a list, take out | ✓ (keys 1–9 too) | ✓ | ✓ one, or many at once |
| New list | ✓ | ✓ | ✓ |
| Rename, delete | | ✓ | ✓ |
| Change the order (drag) | ✓ | | ✓ |
| Show one list only | | ✓ | ✓ |
| Drag items onto a list | | | ✓ |

- **The order is the same everywhere**: change it in one place, and the card,
  the toolbar icon and the app all follow.
- **Deleting a list never deletes what is in it.** The items stay saved; only
  the list is gone. KeepKeep asks first.
- In the app, the search also finds list names.

## Good to know

- A list name can be up to 40 characters.
- Lists are part of your [backup](08-backup.md). Importing a backup joins its
  lists with yours by name, so nothing is doubled.
