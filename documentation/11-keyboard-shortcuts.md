# Keyboard shortcuts

Keys never fire while you type in a box, and never with ⌘, Ctrl or Alt held.

## On Instagram

| Key | Where | What it does |
| --- | --- | --- |
| **D** | pointer over a post | Downloads the photo or video on screen |
| **D** | on a post's own page | The same, wherever the pointer is |
| **D** | in a story or highlight | Downloads the stories (see [Anonymous story viewing and downloading](04-stories.md)) |
| **Shift**-click | the Download button of a post | Downloads only the photo or video on screen |
| **1**–**9** | the card after saving | Puts the item in that list, or takes it out |
| **←** / **→** | pointer over a video | Back / forward 5 seconds |
| **Space** or **K** | pointer over a video | Play / pause |

## In the KeepKeep app

| Key | What it does |
| --- | --- |
| **⌘/Ctrl-A** | Selects everything shown |
| **Shift**-click | Selects a range of cards |
| **Esc** | Clears the selection; closes the side panel |
| **← / →** (or **↑ / ↓**) | Previous / next item in the side panel |
| **F** | Shows the post large, and back |
| **Backspace** | From a post opened in a profile, back to the profile |
| **⌘/Ctrl/Shift**-click on a card | Opens it on Instagram in a new tab |
