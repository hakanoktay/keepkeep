# No duplicate downloads

Downloaded the same post twice? KeepKeep remembers every file it downloaded,
so your folder doesn't fill up with copies like `photo (1).jpg`.

## Where it works

```
No duplicate downloads
│
├── every download, wherever it starts
│   ├── on Instagram
│   ├── KeepKeep's toolbar icon
│   └── the KeepKeep app
└── The KeepKeep app → Downloads
```

## What happens

- **Before downloading a file, KeepKeep checks whether it downloaded it
  before.** It recognises the photo or video itself, not its file name.
- **Already downloaded** files are skipped and shown as "Downloaded before"
  with the date. A **Download again** button saves them anyway.
- **A better version is never skipped.** A video you saved in 720p is
  downloaded again when 1080p is possible now.
- If Chrome knows the download failed or the file was removed, it is
  downloaded again.

## The Downloads page

In the KeepKeep app, **Downloads** lists every post and story KeepKeep
downloaded, newest first: the picture, the account, the date and how many
files. Click one for **Download again** and **Save to Media**.

- **Skip downloaded before**: on by default. Turn it off to always download
  everything.
- **Clear this list**: KeepKeep forgets what it downloaded. Your files stay.

## Good to know

- **KeepKeep can't see your Downloads folder.** Chrome doesn't let extensions
  look at your files, so KeepKeep remembers what it downloaded, not what is
  still there. A file you deleted, moved or renamed still counts as
  downloaded: use Download again.
- The list starts with KeepKeep 1.1; earlier downloads aren't in it.
- The list stays in this browser: it isn't part of a backup and doesn't move
  to another computer. Clearing it, or removing KeepKeep, empties it.
- A post removed from Instagram can't be downloaded again; the files you
  already have stay yours.
