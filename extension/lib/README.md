# Third-party code

`mediabunny.min.mjs` is [Mediabunny](https://github.com/Vanilagy/mediabunny) 1.61.1, a media toolkit that KeepKeep uses (in `../video-join.js`) to join Instagram's separate video and audio streams into one MP4 and to convert it to H.264.

- License: MPL-2.0, in `mediabunny.LICENSE`
- Source: https://github.com/Vanilagy/mediabunny
- Unmodified: the file is the library's published minified build, copied as is.
